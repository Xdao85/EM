How to use the portal

A four-step routine for each module, the keyboard shortcuts of the portal, and suggestions for using the simulations in class.

For students: how to study a module

1 · Read the idea

Start with the theory section. Write each boxed formula in your own notes and say what every symbol means and what its unit is.

2 · Predict, then simulate

Before you move a slider, predict what will happen. Then test it. A wrong prediction is the most useful moment of the lesson.

3 · Work the examples

Cover the solution and try each worked example on paper first. Use the simulation readouts to check your numbers.

4 · Quiz and mark done

Take the 5-question quiz and read every explanation, including the ones you got right. Then press Mark done in the toolbar.

Open the course through index.html to get the menu, progress tracking and the Notes drawer: it keeps private notes for each module, and Export all notes downloads them as one Markdown file for revision before the exam.

For instructors: teaching with the portal

Presenting in class

  • Press Present (or F) to hide the menu and toolbar; step through modules with [ and ].
  • Use Ctrl + to enlarge text and formulas for the back row.
  • Run each simulation live and ask the class to predict the result before you change a parameter.

Sharing modules

  • The link button in the toolbar copies a direct address such as index.html#/topic1/phasors.html, which opens the portal on that module.
  • Put these links in your LMS, slides or homework sheets.
  • Every page also works on its own and can be opened in a new tab.

Lesson pattern

  1. Hook: open the simulation first and pose one question.
  2. Theory: derive the key formula on the page.
  3. Check: solve one worked example together with numbers from the simulation.
  4. Exit ticket: students take the module quiz and mark it done.
